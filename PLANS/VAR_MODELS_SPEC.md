### 2.1 核心功能
實作統計波動率模型以預測價格波動與風險度量。提供 VaR（Value at Risk）計算、波動率預測、尾部風險評估等核心風險度量功能。

## 3. 核心概念與理論基礎

### 3.1 VaR 定義
**VaR(α, h) = 第 α 分位數的 h 期損失**
- α: 信賴水準（如 99% → α = 0.01）
- h: 持有期（如 1 天、10 天）
- 解讀：在正常市況下，h 期內損失超過 VaR 的機率為 (1-α)

### 3.2 Expected Shortfall (ES / CVaR)
**ES(α) = E[L | L > VaR(α)]**
- 尾部期望損失，解決 VaR 非次可加性與尾部風險盲區
- Basel III/IV 指定 ES 為標準風險度量

### 3.3 三大計算流派

| 方法 | 核心假設 | 優點 | 缺點 |
|------|----------|------|------|
| **參數法** | 報酬常態分佈（或 t 分佈） | 計算快、平滑、易解釋 | 低估肥尾、假設脆弱 |
| **歷史模擬法** | 歷史報酬分佈 = 未來分佈 | 無分佈假設、捕捉肥尾 | 需長歷史、對舊數據敏感、非平滑 |
| **蒙地卡羅** | 指定隨機過程（GBM、Heston、跳躍擴散） | 靈活、支援路徑相依、衍生品友善 | 計算重、模型風險高 |

### 3.4 波動率模型體系

| 模型 | 公式核心 | 適用場景 |
|------|----------|----------|
| **EWMA** | σ²_t = λσ²_{t-1} + (1-λ)r²_{t-1} | RiskMetrics 標準，λ=0.94 |
| **GARCH(1,1)** | σ²_t = ω + αr²_{t-1} + βσ²_{t-1} | 捕捉波動聚集、均值回歸 |
| **EGARCH** | ln(σ²_t) = ω + α|z_{t-1}| + γz_{t-1} + βln(σ²_{t-1}) | 捕捉槓桿效應（非對稱） |
| **GJR-GARCH** | σ²_t = ω + αr²_{t-1} + γr²_{t-1}I(r<0) + βσ²_{t-1} | 非對稱衝擊、實務常用 |
| **HAR-RV** | RV_t = β₀ + β₁RV_{t-1} + β₂RV_{t-1:5} + β₃RV_{t-1:22} | 已實現波動率、高頻資料 |
| **隨機波動率 (SV/Heston)** | dσ² = κ(θ-σ²)dt + ξσdW | 衍生品定價、隱含波動率面 |

## 4. 詳細方法論

### 4.1 參數法 VaR（常態/t 分佈）
```
VaR = -μ_h + z_α × σ_h
其中：
  μ_h = h × μ_1（假設無漂移或用預測均值）
  σ_h = √h × σ_1（平方根時間規則，僅限 i.i.d.）
  z_α = 常態分佈 α 分位數（或 t 分佈自由度 ν）
```
**Cornish-Fisher 展開修正肥尾/偏態**：
```
z_α* = z_α + (z_α²-1)S/6 + (z_α³-3z_α)K/24 - (2z_α³-5z_α)S²/36
```

### 4.2 歷史模擬法 VaR
```
步驟 1：取得過去 N 日對數報酬 r_{t-N+1}, ..., r_t
步驟 2：依投組權重計算歷史投組報酬序列
步驟 3：排序，取第 ⌈αN⌉ 小值為 VaR
步驟 4：ES = 該分位數以下所有觀測值的平均
```
**加權歷史模擬**：近期觀測權重更高（指數遞減），解決結構性變化問題。

### 4.3 蒙地卡羅 VaR
```
步驟 1：校準隨機過程參數（GBM: μ,σ；Heston: κ,θ,ξ,ρ,v₀）
步驟 2：模擬 M 條路徑，每條 h 步
步驟 3：計算每條路徑的投組損益
步驟 4：取分位數為 VaR，尾部平均為 ES
```
**變異數縮減**：反變量、控制變量、準隨機序列、重要性採樣。

### 4.4 多資產投組 VaR
```
投組方差：σ²_p = w' Σ w
其中 Σ = 共變異數矩陣（需正定）

相關性建模：
- 靜態樣本相關（易不穩定）
- DCC-GARCH：動態條件相關
- 因子模型：Σ = B Ω B' + D（降維、正則化）
- 隨機矩陣理論 (RMT) 去噪
```

### 4.5 回測與模型驗證
| 測試 | 原假設 | 統計量 |
|------|--------|--------|
| **Kupiec POF** | 違背率 = α | LR_pof = -2 ln[(1-α)^{N-x} α^x / (1-x/N)^{N-x} (x/N)^x] |
| **Christoffersen 獨立性** | 違背事件獨立 | LR_ind 基於馬可夫轉移矩陣 |
| **Christoffersen 條件覆蓋** | POF + 獨立 | LR_cc = LR_pof + LR_ind |
| **ES 回測 (Acerbi-Szekely)** | ES 條件期望正確 | Z_ES = (1/N) ∑ (L_t - ES_t) / se |

**Basel 橙/紅區邏輯**（250 日窗，99% VaR）：
- 綠區：違背 0-4 次 → 無資本費
- 橙區：5-9 次 → 資本費乘數 1.5-1.85
- 紅區：≥ 10 次 → 資本費乘數 2.0-2.5，強制改用標準法

### 4.6 壓力測試與情境分析
- **歷史情境**：1987 黑色星期一、2008 金融海嘯、2020 COVID、2022 加息
- **假設情境**：利率平移 ±200bp、股市 -20%、波動率 +100%、流動性枯竭
- **反向壓測**：給定損失額度，反推所需市場變動

## 6. 品質門檻
部署前必須通過：

- [ ] 回測 250 日窗口：Kupiec POF p-value > 0.05
- [ ] 回測 250 日窗口：Christoffersen 獨立性 p-value > 0.05
- [ ] Basel 區域為綠區（違背 ≤ 4 次 @ 99%）
- [ ] ES 回測通過（Acerbi-Szekely Z-stat 不顯著）
- [ ] 多資產共變異數矩陣正定（最小特徵值 > 1e-10）
- [ ] 計算時間符合 SLA（單投組 < 500ms；全書 < 30s）
- [ ] 參數穩健性：微擾輸入 ±10% → VaR 變動 < 15%
- [ ] 無 look-ahead bias（僅用 t-1 及之前資訊預測 t）
- [ ] 文件化模型假設、限制與適用市場機制
