## 專案 3：[libracoder/kiri](https://github.com/libracoder/kiri) (★ 2334)

- **語言**：`Rust` | **說明**：A small, fast container runtime for macOS, Windows and Linux

## libracoder/kiri – 深度技術剖析

**專案定位** – 一個用 Rust 書寫的超輕量級容器時序，支援 macOS/Windows/Linux，旨在完全取代傳統的 Docker Engine 堆棧（無 runc、無 shim、無 dockerd），並提供毫秒級啟動延遲。

---

### 1. 用途（有咩用）

| 面向              | 解決的核心痛點                                                | 核心功能與技術亮點                                                                                                                                                |
| ----------------- | ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **極速啟動**      | 傳統容器運行時（runc + dockerd）啟動時間 ≥ 200 ms，成為瓶頸。 | • 客製化 10 MB Linux 內核（基於 musl+static Rust）<br>• PID 1 為單一 900 KB Rust 代理，負責 namespace + cgroup 克隆<br>• 使用 `clone3` 直接建立容器，省去 shim 層 |
| **極簡架構**      | Docker 堆棧的複雜性與記憶體佔用過高。                         | • 單一二進制文件（≈ 1 MB）<br>• 無外部依賴，完全靜態編譯<br>• 虛擬機在 60 s 閒置後進入睡眠狀態，進一步節省資源                                                    |
| **Docker 相容性** | 現有工具（CLI、Compose、Buildx）無法直接替換執行時。          | • 完全實現 Docker Engine API<br>• 支援 `docker` CLI、Compose、Buildx、Docker Desktop UI 整合<br>• 使用 vsock 與 PID 1 代理通信，透明化虛擬機內核                  |
| **多平台支援**    | 容器工作負載需要跨作業系統一致的執行時。                      | • 單一代碼庫支援 macOS、Windows、Linux<br>• 透過 Hyper-V/VMware 虛擬化（Windows）或 utrace（macOS）實現 VM 克隆                                                   |

**技術創新亮點**

- **單步克隆** – `clone3` 一次性進入網路、IPC、 mount、PID 等命名空間，並設定 cgroup 配額，省去傳統的 `unshare` + `setns` 序列。
- **靜態 Rust 代理** – 代理本身是 Rust 編寫，內嵌 OCI 規範解析器，並提供 vsock 端點，實現宿主與客體之間的零拷貝控制流。
- **內核級節電** – 虛擬機採用可休眠的輕量級 VM（如 Firecracker 風格），60 s 無活動自動睡眠，醒來時間 < 5 ms。
