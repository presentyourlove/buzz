## 3. 核心概念與理論基礎

### 3.1 趨勢跟隨為何有效
利用資產價格的序列相關性，來源包括：
- **行為偏誤**：錨定效應、從眾、處置效應 → 價格緩慢調整
- **機構資流**：退休基金再平衡、央行干預、指數追蹤
- **風險溢價**：趨勢跟隨類似持有隱含選擇權的長方向

### 3.2 核心特徵
| 特徵 | 說明 |
|------|------|
| **正偏態** | 大賺多於大賠（危機阿爾法：2008 +22%、2022 +18%） |
| **低勝率、高賠付比** | 勝率 ~35-40%，平均賺/賠 ~2.5-3.0x |
| **緩慢 bleed，快速獲利** | 震盪市小虧損累積，趨勢市大獲利 |
| **相關性動態** | 風險偏好時多資產同向做多，風險厭惡時同向做空 |

### 3.3 關鍵指標體系
| 指標 | 目標基準 |
|------|----------|
| 年化夏普 | 0.6-0.9（扣成本後） |
| 最大回撤 | -15% 至 -25% |
| Calmar 比率 | > 0.5 |
| 偏態 | > 0（正偏態） |
| 危機表現 | 極端市場正報酬 |

## 4. 詳細方法論

### 4.1 趨勢訊號生成器

#### 雙移動平均線交叉
```
快線：EMA/SMA(short_window)
慢線：EMA/SMA(long_window)
訊號：sign(快線 - 慢線)
常用組合：10/50、20/100、50/200、100/300
```

#### 唐奇安通道突破
```
N 期高點通道：High_N = max(High_{t-N+1...t})
N 期低點通道：Low_N  = min(Low_{t-N+1...t})

進場：
  多單：價格突破 N 期高點
  空單：價格跌破 N 期低點

出場：
  平多：價格跌破 M 期低點 (M < N)
  平空：價格突破 M 期高點

龜urtle 原始規則：
  System 1: N=20 進場, M=10 出場
  System 2: N=55 進場, M=20 出場
  跳過規則：若上一個 System 1 突破獲利，跳過下一個 System 1 訊號
```

#### 凱特納通道
```
中線：EMA(20)
上軌：EMA(20) + 2 × ATR(10)
下軌：EMA(20) - 2 × ATR(10)

突破上軌 = 趨勢進場
使用波動率自適應頻帶 (ATR) 而非固定標準差
```

#### 動量訊號
```
M 期動量：r_{t-M,t} = log(P_t / P_{t-M})
訊號：sign(動量)
常見：3 個月、6 個月、12 個月動量
可加入風險調整：動量 / 實現波動率
```

### 4.2 ATR 部位計算
```
真實波幅：TR = max(High-Low, |High-PrevClose|, |Low-PrevClose|)
ATR(N) = N 期 TR 平均

部位計算：
  單筆風險金額 = 帳戶淨值 × risk_fraction
  每 ATR 價值   = ATR(20) × point_value
  部位大小      = 單筆風險金額 / (停損_ATR倍數 × 每 ATR 價值)

範例：
  淨值: $1,000,000
  風險比例: 1% ($10,000/筆)
  原油 ATR(20): $2.50
  Point value: $1,000/$1
  停損: 2 ATR = $5,000/張
  部位: $10,000 / $5,000 = 2 張

龜urtle 單位：
  1 unit = 1% 淨值 / (ATR × point_value)
  單一市場最多 4 units，相關群組最多 10 units
```

### 4.3 波動率縮放
```
目標波動率法：
  target_vol = 10% 年化（典型 CTA）
  current_vol = 已實現波動率或 ATR 隱含波動率
  position_scalar = target_vol / current_vol

  高波動 → 小部位
  低波動 → 大部位
  維持跨工具、跨時間的風險貢獻恆定

多資產趨勢投組應用：
  對每個工具 i：
    signal_i = sign(趨勢指標)
    vol_i = 工具 i 的已實現波動率
    weight_i = signal_i × (target_vol / vol_i) / N_instruments
```

### 4.4 CTA 投組建構

#### 市場選擇標準
- 足夠流動性（未平倉量、成交量）
- 資料可用性（10+ 年以上）
- 合理交易成本
- 與既有投組市場低相關

#### 風險預算跨板塊分配
| 板塊 | 風險預算 | 典型市場數 |
|------|----------|------------|
| 股票指數 | 20-25% | 5-8 (ES, NQ, NK, SX5E, HSI) |
| 固定收益 | 25-30% | 5-8 (ZN, ZB, Bund, Gilt, JGB) |
| 外匯 | 20-25% | 6-10 (EUR, GBP, JPY, AUD, CAD, CHF) |
| 商品 | 20-25% | 10-15 (CL, GC, SI, NG, Corn, Soy) |

#### 風險平價原則
- 每個工具貢獻等量風險（波動率加權）
- 每板塊貢獻大致等量風險
- 防止單一市場或板塊主導

#### 相關性管理
- 趨勢訊號跨市場相關（風險偏好時全做多）
- 監控投組層級相關性
- 考慮對沖高相關部位（如已做多 ES 則減碼 NQ）

### 4.5 震盪損失管理
震盪（快速反轉的假突破）是趨勢跟隨的主要成本：

```
緩解措施：
1. 確認延遲：訊號產生後等待 1-3 天再進場
2. 趨勢過濾：僅順長期趨勢方向交易（如僅 MA(200) 上方做多）
3. 波動率過濾：ADX < 20 時不進場（無趨勢）
4. 頻帶過濾：要求價格突破 MA 達 X% 以上才觸發
5. 多時間框架：短、中、長期趨勢一致才進場
6. 初始減碼，確認後加碼

成本權衡：
- 每個過濾減少震盪，但也延遲有效進場
- 部分最佳交易是快速行情，過濾會錯過
- 跨眾多市場分散是最佳震盪緩解
```

## 6. 品質門檻
部署趨勢跟隨策略前必須通過：

- [ ] 趨勢訊號產生正偏態（大賺多於大賠）
- [ ] 系統跨多資產類別、多時段測試通過
- [ ] 實作 ATR 或波動率基礎部位計算
- [ ] 震盪成本量化且可接受
- [ ] 交易成本（滑價+手續費）已從績效扣除
- [ ] 投組分散於 20+ 市場、4+ 資產類別
- [ ] 投組層級監控趨勢部位相關性
- [ ] 定義單一市場與板塊最大部位限制
- [ ] 回撤管理機制就緒（回撤達 X% 降低風險）
- [ ] 系統參數對微小擾動強健（無懸崖效應）

## 7. MVP 實作範圍與驗收標準

### 7.1 MVP 範圍（第一期交付）
| 模組 | 內容 | 驗收標準 |
|------|------|----------|
| **訊號引擎** | 雙 MA 交叉、唐奇安突破、動量、凱特納通道 | 給定價格序列輸出正確訊號序列 |
| **部位計算** | ATR 單位、波動率縮放、龜urtle 單位 | 單元測試覆蓋 ≥ 90%，數值與手算一致 |
| **投組建構** | 風險平價跨板塊配置、相關性監控 | 輸出目標權重，板塊風險貢獻均衡 |
| **回測框架** | 向量化回測、交易成本扣除、績效指標 | 年化報酬、波動、夏普、最大回撤、偏態、Calmar |
| **震盪分析** | 震盪識別、成本分解、緩解措施回測 | 輸出震盪筆數、成本佔比、各過濾效果比較 |
| **報告輸出** | 策略報告模板自動填充 | Markdown 格式，含所有關鍵指標與危機表現 |

### 7.2 非功能性需求
- **效能**：40 市場、20 年日頻全回測 < 3 秒
- **精度**：雙精度浮點，ATR 計算與標準定義一致
- **可重現**：固定種子、記錄完整參數、資料版本、交易成本假設
- **擴充性**：策略模式註冊新訊號、新過濾、新部位法則

## 8. 相依性與整合點
- **上游**：需清洗後的期貨/現貨價格資料（OHLCV）、連續合約處理、點值/保證金規格
- **下游**：執行引擎（訂單切片、滑價模型）、風險管理（即時 VaR、保證金監控）
- **並行**：var-models（波動率輸入部位縮放）、portfolio（風險平價優化）、execution（TCA）

## 9. 風險與限制
- **震盪市場長期 bleed** — 需心理準備接受長期小虧損
- **參數敏感度** — 過度優化導致走樣前表現，需強健性檢驗
- **流動性風險** — 極端市場滑價遠超常態，需流動性調整 VaR
- **相關性崩塌** — 危機時跨資產相關性趨近 1，分散效果失效
- **監管/保證金變更** — 交易所保證金調整影響槓桿與部位上限
- **var-models 技能缺失** — 目前僅 frontmatter，波動率縮放功能依賴其補強

## 10. 後續擴充建議（第二期）
- **機器學習趨勢分類**：HMM/狀態空間模型識別趨勢/震盪狀態
- **自適應參數**：線上學習調整 MA 窗口、突破期限
- **替代資料增強**：衛星數據、船舶追蹤、庫存數據確認商品趨勢
- **多因子趨勢**：結合動量、載息、價差、季節性
- **選擇權覆蓋**：動態 Delta hedging、尾部風險保護
- **加密貨幣 24/7 適應**：資金費率套利、永續合約基差趨勢
